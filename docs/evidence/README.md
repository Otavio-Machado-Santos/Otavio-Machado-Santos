# Evidências do perfil

Capturas reais da renderização do GitHub em 09/10/2026. As ilustrações em `assets/` são elementos de apresentação; estes arquivos registram seu uso na página real.

- `antes.jpg`: perfil anterior à mudança.
- `preview-desktop.jpg`, `preview-mobile.jpg`, `preview-real.gif`: README na branch, com o novo retrato ASCII e o histórico no início.
- `publicado-entrada.jpg`: frame original da gravação da página pública, com avatar laranja e retrato completo.
- `publicado-historico.jpg`: calendário anual e barras mensais na página pública.
- `publicado-desktop.jpg`, `publicado-mobile.jpg`: página pública completa, no desktop e em 390 px. O mobile foi capturado com movimento reduzido, usando a versão estática do retrato.
- `publicado-real.gif`: gravação contínua de aproximadamente 13 segundos da página pública. Mostra o retrato se formando, a rolagem até o calendário e a abertura dos últimos commits públicos. GIF codificado a partir dos frames reais do navegador, preservando seus intervalos.

Validação: 12 imagens do README carregadas; página mobile com largura de 390 px, sem overflow horizontal; histórico de commits expandido; versão estática carregada com `prefers-reduced-motion`. Calendário e estatísticas são snapshots de 09/10/2026: 2.080 contribuições na coleta, incluindo commits e outras atividades, com data visível. A soma dos dias retornados pela API corresponde ao total exibido. Não foram executados os projetos vinculados nem criados workflows de Actions.
